# 60Pins 太空数据探索

## 项目简介
一个用于探索模拟太空任务中温度与光照数据的互动网页。

## 功能列表
任务简介与四步流程
从 JSON 加载 8 条数据
JavaScript 动态生成数据表格
Chart.js 温度折线图
四个数据摘要（最高/最低/平均温度、最大光照）
三题互动测验（即时反馈、得分、重新开始）
手机适配（表格横向滚动、按钮易点击）

## 技术栈
HTML5 / CSS3 / 原生 JavaScript / Chart.js / JSON / GitHub Pages

## 如何本地运行
1. 用 VSCode 打开项目文件夹
2. 右键 index.html → Open with Live Server
3. 浏览器会自动打开预览页面

> 注意：不要双击打开 index.html，否则数据无法加载。
