## 如何修改数据
1. 打开 data/mission-data.json
2. 修改 time / temperature / light 的值
3. 保存，刷新页面

## 如何重新发布到 GitHub Pages
1. 在 GitHub 仓库 Settings → Pages
2. Source 选择 Deploy from a branch
3. 选择 main 分支，/root 文件夹
4. Save，等待链接生成
